# DokaCamera-iOS

Film camera app with 24 professional film filters, ported from Android to iOS.

## Features
- 24 film filter presets (Fujifilm, Kodak, Agfa, Doka)
- Real-time camera preview
- Photo library integration
- Native iOS Swift implementation

## Build Instructions
1. Download and extract `DokaCamera_iOS_完整项目.zip`
2. Open Xcode, create new iOS App project
3. Import all files from the extracted folder
4. Build and run on device

## Requirements
- iOS 14.0+
- Xcode 14.0+
- Physical device (camera required)

Ported from Android APK: com.ydgn.doka v1.3.12
